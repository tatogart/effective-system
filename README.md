# Фенестра 9

Рабочий стол в духе Windows, который целиком живёт в одном файле `index.html`:
ни сборки, ни зависимостей, ни сети. Скачайте файл, откройте двойным кликом в
браузере — и получите установщик с ключом продукта, загрузочный экран, оконную
оболочку с несколькими рабочими столами, шестнадцать приложений, живые обои,
синий экран и среду восстановления.

```
git clone https://github.com/tatogart/effective-system.git
open effective-system/index.html        # macOS
xdg-open effective-system/index.html    # Linux
```

Файл открывается и напрямую из папки (`file://`), и с любого статического
сервера (`npx http-server .`). Интернет нужен только для веб-шрифтов — без него
система работает на системных шрифтах.

## Установка

При первом запуске открывается установщик из семи шагов: язык, лицензионное
соглашение, ключ продукта, выбор диска, копирование файлов, учётная запись,
завершение. Дальше — загрузочный экран и рабочий стол.

**Ключ продукта** имеет вид `FNSTR-XXXXX-XXXXX-XXXXX-XXXXX` и проверяется
контрольной суммой: символы берутся из алфавита без похожих друг на друга букв,
а последний символ дополняет сумму остальных до значения, кратного 24. Кнопка
«Сгенерировать» выдаёт корректный ключ; «Активировать позже» тоже работает —
тогда в углу стола появляется водяной знак, который снимается в
Параметрах → Активация. Это игрушка, а не защита.

Повторить установку можно в любой момент: Пуск → Завершение работы →
«Переустановить систему», или `wipe` в среде восстановления.

## Среда восстановления

Отдельный экран поверх системы — как WinRE. Попасть туда можно тремя путями:
**F8** на загрузочном экране, Пуск → Завершение работы → «Среда восстановления»,
или клавиша **R** на синем экране.

| Действие | Что делает |
|---|---|
| Продолжить | выходит и загружает систему |
| Восстановление файлов | возвращает исходные папки и документы, настройки не трогает |
| Сброс параметров | тема, акцент, обои и звук — к значениям по умолчанию |
| Проверка диска | обходит дерево файлов и отчитывается о находках |
| Ключ продукта | показывает ключ и состояние активации |
| Полный сброс | стирает всё и запускает установщик |

Внизу — консоль: `help`, `boot`, `restore`, `reset`, `fsck`, `key`, `wipe`, `clear`.

## Оболочка

- окна: перетаскивание, изменение размера за любой край и угол, сворачивание,
  разворачивание, двойной клик по заголовку, анимации открытия и закрытия;
- прилипание к краям: левый и правый — половина экрана, верхний — весь стол;
- **несколько рабочих столов**: кнопка «Представление задач» рядом с «Пуском»,
  до четырёх столов, окна переносятся между ними из контекстного меню;
- панель задач с индикаторами, превью окна при наведении и переключателем столов;
- меню «Пуск» с поиском по приложениям и файлам;
- трей: уведомления, тема, сеть, громкость, часы с календарём; экран блокировки;
- **центр уведомлений** хранит историю событий, **стикеры** живут прямо на столе;
- диалог **«Выполнить»** (Win+R) открывает приложение, адрес или файл по имени;
- контекстные меню на столе, значках и файлах; корзина с восстановлением;
- горячие клавиши: **Win** — «Пуск», **Win+R** — выполнить,
  **Ctrl+Alt+Del** — диспетчер задач, **Alt+Tab** — переключение окон,
  **F5** — обновить стол, **Esc** — закрыть меню.

## Обои

Шесть вариантов, и два из них живые — рисуются в `<canvas>` поверх рабочего стола:

| Обои | Что это |
|---|---|
| Сумерки, Сияние | градиентные заливки от акцентного тона |
| **Космос** | звёздное поле с параллаксом и редкими кометами |
| **Поток** | семь волновых лент, медленно перетекающих друг в друга |
| Сетка, Бумага | спокойный фон для работы |

Анимация останавливается, когда вкладка в фоне или включилась заставка.

## Приколы

`crash` в терминале — синий экран с кодом остановки и обратным отсчётом.
`matrix` — зелёный дождь на весь экран. `party` — конфетти. `sudo` — отказ.
`note текст` — стикер прямо из командной строки. Полторы минуты без действий —
заставка с логотипом, который бьётся об углы и считает попадания.
Семь кликов по версии в «О системе» — тоже конфетти. `winver` и `regedit`
в диалоге «Выполнить» отвечают в духе оригинала.

## Как это сделано

Токены цвета построены на `oklch` от одного тона: акцент задаёт и нейтральные
поверхности, и обои, поэтому смена акцентного цвета перекрашивает систему
целиком. Светлая и тёмная темы описаны для всех трёх состояний переключателя —
выбор пользователя и системная настройка `prefers-color-scheme`.
Файловая система — дерево объектов; файлы, корзина, настройки и ключ хранятся
в `localStorage`. Шрифты: DM Sans для интерфейса, JetBrains Mono для терминала.

Слой окон (`#windows`) растянут на весь стол, поэтому у него
`pointer-events: none`, а у самих окон — `auto`: иначе прозрачный слой
перехватывает клики и значки на рабочем столе перестают открываться.

Браузер показывает страницы в `<iframe sandbox="allow-same-origin">` с
`srcdoc`: разметка и стили работают, скрипты внутри отключены, а переходы по
ссылкам перехватываются оболочкой и превращаются в навигацию по файловой системе.

Графики в диспетчере задач — одна серия на график, общая шкала от нуля,
ненавязчивая сетка и подпись значения при наведении; двух осей на одном
графике нет принципиально.

## Сборка версии для артефакта

`index.html` — самостоятельный документ. Хостинг артефактов оборачивает
страницу в собственный каркас, поэтому для публикации нужен тот же файл без
`<!doctype>`, `<html>`, `<head>` и `<body>`:

```
node tools/build-artifact.mjs   # → dist/artifact.html
```

# Фенестра 9

Рабочий стол в духе Windows, который целиком живёт в одном файле `index.html`:
ни сборки, ни зависимостей, ни сети. Откройте файл в браузере — и получите
оконную оболочку с панелью задач, меню «Пуск» и набором работающих приложений.

## Что внутри

**Оболочка**

- окна: перетаскивание, изменение размера за любой край и угол, сворачивание,
  разворачивание, двойной клик по заголовку, порядок по z-index;
- прилипание к краям: левый и правый край — половина экрана, верхний — на весь стол;
- панель задач с индикаторами активных окон и контекстным меню на кнопке;
- меню «Пуск» с поиском по приложениям и недавним файлам;
- трей: тема, сеть, громкость, часы с календарём; экран блокировки;
- контекстные меню на рабочем столе, значках и файлах.

**Приложения**

| Приложение | Что умеет |
|---|---|
| Проводник | дерево папок, навигация, создание и удаление, строка состояния |
| Блокнот | чтение и запись файлов, `Ctrl+S`, счётчик строк, слов и символов |
| Терминал | `ls`, `cd`, `pwd`, `cat`, `open`, `mkdir`, `touch`, `rm`, `echo`, `theme`, `date`, `apps`, `neofetch`, история по стрелкам |
| Калькулятор | арифметика, процент, корень, `1/x`, ввод с клавиатуры |
| Кисть | рисование, ластик, толщина, палитра, сохранение PNG в «Изображения» |
| Фото | просмотр картинок из «Изображений», листание, удаление |
| Сапёр | поле 9×9, 10 мин, флажки, таймер, первый ход всегда безопасен |
| Параметры | тема, акцентный цвет, обои, звуки интерфейса, сведения о системе |

**Файловая система** — дерево объектов в памяти; файлы, настройки и содержимое
папок сохраняются в `localStorage`, поэтому после перезагрузки вкладки всё на месте.
Кнопка «Сбросить систему» в Параметрах возвращает исходное состояние.

## Оформление

Токены цвета построены на `oklch` от одного тона: акцент задаёт и нейтральные
поверхности, и обои, поэтому смена акцентного цвета перекрашивает систему целиком.
Светлая и тёмная темы описаны отдельно и учитывают три состояния —
выбор пользователя и системную настройку `prefers-color-scheme`.
Шрифты: DM Sans для интерфейса, JetBrains Mono для терминала и цифр.

## Запуск

```
open index.html          # macOS
xdg-open index.html      # Linux
```

Либо любой статический сервер, например `npx http-server .`.
